## Observations

Haiku correctly captured the semantic requirements (method signatures, types, MOCK_METHOD syntax, smart pointers) but missed all project-specific structural conventions: include guard format, `final`, `m_` prefix, file separation, brace style, blank-line spacing, and full include paths.

These are exactly the conventions codified in the skills — the benchmark confirms the skills add real value beyond what the model produces by default.
